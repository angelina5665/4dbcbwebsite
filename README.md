# MY4D / 4DVIP88

This repository publishes the independent Malaysia 4D results reference at [my4d.co](https://my4d.co/), branded **4DVIP88**.

The site keeps provider-specific draw dates separate from its own data-update timestamp. Its publication workflow validates the complete configured provider set before updating the live result pages. Read the public [data and freshness methodology](https://my4d.co/methodology.html) for source, archive and correction limits.

This repository does not accept wagers or represent the result providers named on the website. Results are provided for reference and should be verified with the relevant provider.
