What this result page covers

Toto and SportsToto are common ways people refer to the same provider. The word sports is used here only as part of the Sports Toto name.

The 4D card shows the top-three, special and consolation groups. A separate card preserves the 5D, 6D and lotto fields from the same Sports Toto draw so that unlike result formats are not merged into one table.

How to read and verify the result

Check the product label as well as the draw number. A 4D number, a masked 6D combination and a lotto ball set describe different result formats and should not be compared as if they were interchangeable.

The current pipeline compares Sports Toto draw metadata, 4D prize groups, 5D and 6D fields, lotto balls, bonus ball and jackpot fields with a second aggregation feed. Provider rules still control prize and claim information.

The imported update time records when the data file changed. It does not by itself establish official status, finality or endorsement.
