Methodology & Sources

Page updated: 6 September 2026

Current display process

  1. A scheduled script imports result information from 4d4d.co for the supported providers other than Grand Dragon.
  2. Grand Dragon results come from the 4dmoon.com feed. Using these two sources for different records is not an independent two-source comparison of each result.
  3. The importer checks that recorded draw dates and weekdays agree, selects the newest provider date and puts the recent-date list in order.
  4. Before publication, page-generation checks require the complete supported provider set, expected number formats and counts, matching related draw details and a seven-day maximum result age. These checks use results.json but do not prove the imported numbers are correct.
  5. The accepted data generates crawlable homepage, provider, regional and Malay result HTML. Browser JavaScript adds interactive features; if the JSON request fails, the last generated result remains visible. Retained dated archives are not refreshed by this scheduled job.
  6. The update time records an import run. It can change even when the draw numbers have not changed, and a timestamp-only change can trigger publication.

Current upstreams and authorisation

The code requests https://4d4d.co/ and https://www.4dmoon.com/feedwest.json. On 24 August 2026, the site owner confirmed that leadership had obtained permission to republish the result information. No private approver identity or credential is stored in the website repository.

These remain third-party aggregation sources. Permission to republish does not make either source an official provider feed, establish provider endorsement or guarantee future accuracy.

Verification warning: a recent timestamp does not independently prove that a number is accurate, complete or final. Check important information directly with the relevant provider.

Current verification record

The scheduled publication checks cover all ten supported result records. They test dates, number formats, prize-group sizes and related product details. A successful check means that the imported data passed those consistency rules, not that a provider independently verified it.

The current updater does not automatically compare Magnum, Da Ma Cai or Sports Toto results between two feeds. A review of an earlier draw does not verify a later draw, even if its update time is recent.

Use the provider name, draw date, draw number where available and prize heading together. Before relying on a result, compare those details with the relevant provider's published information.

Corrections and stale data

If fetching or the required page-generation checks fail, the scheduled job does not publish its new results. The existing website can therefore remain on an earlier draw. Check each card's date: an update time is not a draw time. A later accepted import can change a result, while an older retained archive needs a separate review and correction at its existing URL.

Publication standard

Results are provided for reference, not as predictions or guarantees. Use the reading guidance and provider links to identify the right draw and prize group. The history section lists only the completed draws retained by this site; it is not a complete record of every draw.
