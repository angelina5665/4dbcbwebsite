Methodology & Sources

Page updated: 24 August 2026

Current display process

  1. A scheduled script requests result information from two authorised third-party aggregation endpoints.
  2. It requires the complete reviewed provider set and cross-checks Magnum, Da Ma Cai and Sports Toto fields between the feeds, including draw metadata and Sports Toto extended results.
  3. For the retained 23 August 2026 snapshot, the remaining providers were checked on provider-owned or operator-family surfaces and separate dated publishers. Each manual record is bound to the exact provider object with its draw date, draw number where available and a SHA-256 digest.
  4. Exact number lengths, result counts, weekdays, related draw numbers, product-specific fields and a seven-day freshness limit must pass before results.json can be replaced atomically.
  5. The same validated snapshot generates crawlable homepage, provider and regional HTML. A dated archive includes only provider records whose own draw date matches its URL. Browser JavaScript is progressive enhancement; a JSON failure leaves the last generated result visible.
  6. A timestamp-only check does not rewrite the data file or trigger a deployment.

Current upstreams and authorisation

The code requests https://4d4d.co/ and https://www.4dmoon.com/feedwest.json. On 24 August 2026, the site owner confirmed that leadership had obtained permission to republish the result information. No private approver identity or credential is stored in the website repository.

These remain third-party aggregation sources. Permission to republish does not make either source an official provider feed, establish provider endorsement or guarantee future accuracy.

Verification warning: a recent timestamp does not independently prove that a number is accurate, complete or final. Check important information directly with the relevant provider.

Current verification record

The generated data records a dated approval identifier, verification time, source mapping and the exact providers included in an automated cross-check. The 24 August 2026 staging review found agreement across the authorised feeds for Magnum, Da Ma Cai and Sports Toto. Cash Sweep, Sabah 88, Sandakan STC and Singapore Pools matched provider-owned and separate dated pages. Grand Dragon matched operator-family surfaces and two separate dated publishers; their undisclosed upstream lineage cannot be proven from public pages alone.

Those manual records apply only to the exact 23 August snapshot and are deliberately removed by the next accepted scrape. Grand Dragon and the regional records still do not have repeatable automated second-source coverage.

The site owner approved live publication of the reviewed Batch 2-3 snapshot on 24 August 2026. The checked-in policy permits the approved sources only through the fail-closed publication mode. Dated manual verification remains bound to this exact snapshot and does not carry forward to a future changed draw.

Corrections and stale data

If either source is unavailable, a required provider is missing, compared sources disagree, or a date or number fails validation, the import refuses to overwrite the last-known-good snapshot. The automated job regenerates only the newest completed draw. Correcting an older retained archive requires verified retained source data and a dated manual rebuild of its existing URL rather than a duplicate page.

Publication standard

Result pages must add useful context, clear freshness information, internal navigation and correction handling. Dated archives are created only for completed snapshots actually retained by the site. The site does not create empty future dates, spelling-variant doorways or mass-produced provider-and-date combinations.
