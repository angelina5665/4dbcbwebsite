Malaysia 4D Results Data and Freshness Guide

Page updated: 3 October 2026

This page explains how MY4D imports and displays Malaysia 4D result information, what its automated checks can and cannot prove, why provider dates can differ, and which historical records are actually retained. Results are provided for reference only. MY4D is not a lottery operator and does not imply provider affiliation.

Coverage at a glance

  • The current homepage generator expects ten supported result records across West Malaysia, East Malaysia and Singapore sections.
  • Different provider cards may show different draw dates because providers do not necessarily publish on the same day.
  • The page update time records an accepted import run. It is not the same thing as a draw time and does not independently prove that every number is final or correct.
  • The retained public archive currently lists only 23 August, 24 August, 5 September and 6 September 2026. It is not a complete historical database.

Current display process

  1. A scheduled script imports result information from 4d4d.co for the supported providers other than Grand Dragon.
  2. Grand Dragon results come from the 4dmoon.com feed. Using these sources for different records is not an independent two-source comparison of each result.
  3. The importer checks that recorded draw dates and weekdays agree, selects the newest provider date and puts the recent-date list in order.
  4. Before publication, generation checks require the complete supported provider set, expected number formats and counts, matching related draw details and a seven-day maximum result age. These checks test consistency; they do not prove the imported numbers are correct.
  5. Accepted data generates crawlable homepage, provider, regional and Malay result HTML. Browser JavaScript adds interactive features. If a later JSON request fails, the last generated result remains visible.
  6. Retained dated archives are not refreshed by the scheduled results job.

Current upstreams and authorization

The code requests https://4d4d.co/ and https://www.4dmoon.com/feedwest.json. On 24 August 2026, the site owner confirmed that leadership had obtained permission to republish the result information. No private approver identity or credential is stored in the website repository.

These remain third-party aggregation sources. Permission to republish does not make either source an official provider feed, establish provider endorsement or guarantee future accuracy.

Verification warning: a recent timestamp does not independently prove that a number is accurate, complete or final. Check important information directly with the relevant provider.

What the automated checks verify

The scheduled publication checks test dates, number formats, prize-group sizes, related product details, crawlable generated HTML, the MY4D canonical, theme and Dictionary markers, and the complete expected provider set. Passing those checks means the imported data has the expected structure and freshness. It does not mean an operator independently verified the values.

Corrections and stale data

If fetching or a required generation check fails, the scheduled job does not publish the proposed results. The existing website can therefore remain on an earlier draw. Check each provider card’s date rather than assuming the newest site update applies to every provider.

A later accepted import can change a current result. Older retained archives require a separate review and correction at their existing URLs; the automated current-results job does not silently rewrite those archives.

Historical and number-search coverage

The past-results archive lists only completed draws retained by this site. The number-history search preserves leading zeroes and distinguishes ordinary prize tiers from jackpot products, but coverage differs by operator and year. An empty match does not prove a number never appeared outside the retained dataset.

How to read a result responsibly

Use the provider name, provider-specific draw date, draw number where available and prize heading together. Do not treat previous results, dictionary entries or number frequency as predictions. Before relying on an important result, compare it with information published by the relevant provider.
